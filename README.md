# Paas
Plataforma como servicio


es un modelo de computación en la nube que proporciona un entorno completo y preconfigurado para desarrollar, ejecutar y gestionar aplicaciones sin la necesidad de administrar la infraestructura subyacente.
¿Cómo Funciona?
• El proveedor aloja y administra el hardware, los servidores, las redes, el almacenamiento, los sistemas operativos y las bases de datos.
• Los desarrolladores se enfocan de manera exclusiva en escribir el código, implementar la lógica de negocio y realizar pruebas.
• Ofrece herramientas integradas como compiladores, middleware y APIs listas para usar.
Características Principales
• Automatización: Facilita enfoques modernos de DevOps e integración continua (CI/CD).
• Escalabilidad: Permite ajustar los recursos informáticos de forma dinámica según la demanda de la aplicación.
• Reducción de costos: Elimina la necesidad de comprar y mantener costosos componentes de hardware y licencias locales.
Ejemplos Populares
• Google App Engine
• Heroku
• Microsoft Azure App Services
